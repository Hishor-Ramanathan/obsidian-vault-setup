# The Two Columns

Andy Stump's exercise, via [[Become Mentally Dangerous With These Daily Habits]].
Write everything that concerns you on the left. Write only what you can actually
act on next to it. You control nothing on the left — the value is noticing, for
the rest of the month, which column a thought came from.
